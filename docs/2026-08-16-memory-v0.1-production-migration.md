# Memory v0.1 production migration

## Objective

Activate Bob Core's first provider-independent persistent memory store without saving raw conversations automatically or placing database credentials in the iPhone application.

## Approval and migration result

The production migration was explicitly approved by the project owner on 2026-08-16 and applied to the main branch of the dedicated BobAI Memory Neon project.

Post-migration verification confirmed:

- `public.bob_memory_items` exists.
- `public.bob_memory_events` exists.
- The database starts with zero active memories and zero audit events.
- The temporary migration branch was removed after the migration completed.

## Storage behavior

Memory items support personal, project, preference, and fact scopes. Records can be classified as normal or sensitive, searched through PostgreSQL full-text search, deduplicated per owner, and soft-deleted. Memory mutations create audit events without storing provider credentials or raw chat transcripts.

## Privacy controls

- Memory capture is explicit by default.
- Ordinary chat is not automatically persisted.
- Retrieved memories are passed to the model as untrusted factual context, never as system instructions.
- Passwords, API keys, access tokens, private keys, recovery phrases, database credentials, payment-card numbers, government identifiers, and bank-account identifiers are rejected by policy.
- Memory v0.1 does not provide application-level field encryption, so high-risk secrets must not be stored.

## Production activation

The database schema is ready. Bob Core activates memory only when its production environment contains the private pooled Neon connection string and the memory feature is enabled.

Required Bob Core production settings:

```text
DATABASE_URL=<private pooled Neon connection string>
BOB_CORE_MEMORY_ENABLED=true
BOB_CORE_OWNER_ID=rick
BOB_CORE_MEMORY_RETRIEVAL_LIMIT=6
```

The existing Bob Core device token, Z.AI configuration, URL, and iPhone Keychain configuration remain unchanged.

## Acceptance test

After the production environment is configured and redeployed:

1. Say: `Bob, remember that I prefer to be called Rick.`
2. Confirm Bob acknowledges the saved memory.
3. Close and reopen BobAI.
4. Ask: `What do you remember about my name?`
5. Confirm Bob recalls the approved memory.
6. Say: `Bob, forget: I prefer to be called Rick.`
7. Confirm the memory is soft-deleted and an audit event is recorded.

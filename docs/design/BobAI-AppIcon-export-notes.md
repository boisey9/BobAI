# BobAI App Icon Export Notes

Target: iOS AppIcon source image, 1024 x 1024 pixels.

- Export without transparency.
- Keep the near-black rounded-square field, concentric cyan/electric-blue rings, and centered luminous `B`.
- Avoid adding text other than the `B` mark.
- Preserve generous safe space so the mark remains clear at small Home Screen and Spotlight sizes.
- Use the same Core visual vocabulary as `BobCoreView` so launch icon and voice interaction feel like one identity.

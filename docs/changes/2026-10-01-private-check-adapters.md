## Format contracts

- Process results: exact ordered catalog argv, captured exit/signal and stdout/stderr hashes; empty successful compiler outputs supported. Nonzero/signal/missing exits never pass. Process observations need honest authenticated independent runner; logs alone do not prove execution.
- Vitest: actual native start/end timestamps, summary/assertions/counts, executed inventory and failure/pending/todo/skipped consistency. Case identities include file/full name and occurrence ordinal for existing parameterized tests with repeated display names. Full expected inventory, including repeated occurrences, is authoritative; dropping occurrences cannot satisfy it. This does not cryptographically prove a malicious trusted runner executed a particular parameter value.
- Playwright: actual native statistics start/duration and spec ID/project ID identities, nested suite traversal with depth bound, expected/unexpected/skipped/flaky counts and actual successful result status. Flaky/skipped/interrupted/partial outcomes blocked. Actual Playwright format has spec.id, not invented test.testId.
- PostgreSQL/recovery: explicit runner observations and complete required suite set, hash-verified nested Vitest reports and exact qualified case inventory. No raw file path dereferencing or stdout boolean alone. Observed private socket/TCP-off/fsync/stopped fields must originate with authenticated runner; signing does not replace deployed role/RLS acceptance.
- Memory: all fourteen reviewed continuity groups, exact persisted/cold IDs including decisions, actual-PG cleanup modes, eight named lifecycle cases, and runner private/stopped observations. Updated cold script emits decision IDs already compared internally by accepted85; no retrieval semantics changed. New capture-owned-lifecycle-report.mjs consumes actual node:test event stream rather than guessing success from TAP text.

All reports bounded, unknown/incomplete formats fail closed; automated failures/skips retained as non-pass. Empty/missing/partial inventories denied. These formats are local contracts; no live report producer transmits or signs results.
